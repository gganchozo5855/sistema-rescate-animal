# sistema-rescate-animal
Diseño lógico de un sistema para la gestión de rescate y adopción animal.
Sistema de Control de Rescate y Adopción Animal
Este repositorio contiene el diseño lógico de un sistema destinado a gestionar casos de rescate y adopción animal.

Funciones principales
Registrar casos de rescate.
Categorizar la especie del animal.
Asignar voluntarios o veterinarios.
Gestionar el estado de cada caso.
Organización
El proyecto utiliza Gitflow mediante las ramas main, develop y feature.
