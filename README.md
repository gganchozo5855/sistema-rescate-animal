# sistema-rescate-animal
Diseño lógico de un sistema para la gestión de rescate y adopción animal.
Prototipo HTML
El prototipo del Sistema de Control de Rescate y Adopción Animal está compuesto por tres páginas interconectadas:

index.html: página principal con la bienvenida y el resumen del refugio.
reportar.html: formulario para registrar un nuevo caso de rescate.
rescates.html: consulta organizada de los casos registrados.
Organización del proyecto
Los recursos gráficos se encuentran almacenados en la carpeta assets/img. Las páginas incluyen una navegación común y utilizan etiquetas semánticas de HTML5.

Validación
Los archivos HTML fueron revisados mediante el Markup Validation Service de la W3C y no presentaron errores de sintaxis.
